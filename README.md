# Reel Content Templates

The templates I use to plan, write and finish short-form videos for **SS Creative Studio**: Reels, TikTok and YouTube Shorts, in **English and Malayalam**.

| File | Use it for |
|---|---|
| [script-template.md](script-template.md) | 60-second reel script and the Part 1/Part 2 split |
| [captions.md](captions.md) | Bilingual caption formulas |
| [hashtags.md](hashtags.md) | Hashtag sets by content type |
| [on-screen-text.md](on-screen-text.md) | Text overlay rules |
| [end-card.md](end-card.md) | Closing screen and follow card |

## My rules of thumb

- Hook in the **first 2 seconds**.
- Shorts run **exactly 60 seconds**. Longer scripts become **Part 1 / Part 2**.
- On-screen text is **English only**, bold, in the lower part of the frame.
- End by asking viewers to **save and follow**, not to comment.
- Recommend **free AI tools** first, because most of my audience uses free plans.
- Never repost the same video with a new hook. Move to a new topic instead.
