# 60-Second Reel Script Template

| Time | Beat | What to say/show |
|---|---|---|
| 0–2s | **Hook** | A bold claim or question. Example: "10 free Gemini features nobody uses" |
| 2–8s | **Promise** | What the viewer will get by the end |
| 8–50s | **Value** | Numbered points, about 5 to 8 seconds each, with a visual change per point |
| 50–57s | **Payoff** | The best tip last, or a quick recap |
| 57–60s | **CTA** | "Save this and follow for more" |

## Part 1 / Part 2 split

- End Part 1 on a cliffhanger: "Number 6 is the best one. It's in Part 2."
- Start Part 2 with: "Part 2. If you missed Part 1, check my profile."
- Keep the same thumbnail style so the parts look like one series.

## Series format (numbered tools/tips)

```
HOOK:   "[N] free [TOOL] tricks you're not using"
POINT:  "#[n]: [feature name]. [one-line benefit]. [show it on screen]"
CTA:    "Save this. Next: [NEXT TOPIC]. Follow so you don't miss it."
```
